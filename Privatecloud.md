# Private Cloud

## Was ist das?
Eine Cloud-Umgebung, die ausschliesslich von einer einzigen Organisation genutzt wird (Single-Tenant). Sie bietet Cloud-Funktionen wie Self-Service und Automatisierung, läuft aber isoliert im eigenen Rechenzentrum oder auf gemieteter, dedizierter Hardware.

## Unterschied zu normalem On-Prem
* **On-Prem:** VMs und Netzwerke werden manuell vom Admin gebaut.
* **Private Cloud:** Automatisierte Bereitstellung, Portale für Teams, flexible Zuweisung.

## Beispiele / Software
* OpenStack, VMware Cloud Foundation, Azure Stack Hub

## Vor- & Nachteile
* **+** Volle Datensouveränität und Compliance
* **+** Keine fremden Nutzer auf derselben Hardware
* **-** Hohe Hardware- und Lizenzkosten
